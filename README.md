# 🇻🇳 Tầm nhìn Công nghệ Việt Nam 2050

Website prototype trình bày **tầm nhìn phát triển công nghệ Việt Nam đến năm 2050**.

## 📂 Cấu trúc

```text
tam-nhin-cong-nghe-vietnam-2050/
├── index.html
├── scripts.js
├── style.css
└── README.md
```

## 🎯 Mục tiêu

- Trình bày các định hướng công nghệ theo cách trực quan
- Kết hợp nội dung chiến lược với giao diện web tương tác
- Làm nền tảng để mở rộng nội dung về khoa học, công nghệ và đổi mới sáng tạo

## 🛠 Công nghệ

- HTML5
- CSS3
- JavaScript

## ▶️ Chạy

Mở `index.html` bằng trình duyệt hoặc sử dụng static web server.
